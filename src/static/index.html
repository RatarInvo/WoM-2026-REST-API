REST + WebSocket

Build together,
one note at a time.

A small, focused API for shared boards and collaborative notes. Use the REST endpoints for persistence and WebSocket events for a responsive board experience.

https://wom-2026-rest-api.onrender.com/

Quick start

Every REST route is protected.

1. Get a JWT

Sign in through the Notes App authentication service. The token must contain the user subject in sub.

2. Authorize requests

Send the token as a Bearer token on every REST request.

Authorization: Bearer <your-jwt>

REST API

JSON in, JSON out.

Boards

Accessible boards only.

GET/boardsList your boards

Description

Returns boards owned by, or shared with, the authenticated user.

200 OK
[
  {
    "id": 1,
    "name": "Project ideas",
    "owner_id": "uuid"
  }
]
POST/boardsCreate a board

Request body

The name is trimmed and may contain up to 100 characters.

{ "name": "Project ideas" }

Response

{
  "id": 2,
  "name": "Project ideas",
  "owner_id": "uuid"
}
201 Created

Notes

Scoped to accessible boards.

GET/notesList notes

Description

Lists all notes on boards the authenticated user can access, ordered by ID.

200 OK
[
  {
    "id": 12,
    "author_id": "uuid",
    "board_id": 2,
    "note": "Remember the launch date",
    "pos_x": 120,
    "pos_y": 80,
    "width": 220,
    "height": 160,
    "color": 0,
    "board": { "id": 2, "name": "Project ideas" }
  }
]
GET/notes/:idGet one note

Path parameter

id must be an integer note ID. The note must belong to an accessible board.

200 OK404 if not found
{ "id": 12, "note": "Remember the launch date", "board": { "id": 2, "name": "Project ideas" } }
POST/notesCreate a note

Request body

note must contain text. board_id must be a positive integer for a board you can access.

{
  "note": "Remember the launch date",
  "board_id": 2
}

Response

{ "user": "Alex", "msg": "Note created", "id": 12 }
201 Created
PUT/notes/:idUpdate text or layout

Request body

Send one or more fields. Empty bodies are rejected.

  • note: non-empty string
  • x, y: 0–100000
  • width, height: 50–5000
  • color: 0–20

Example

{ "x": 180, "color": 3 }
200 OK
DELETE/notes/:idDelete a note

Description

Deletes a note on an accessible board.

200 OK
{ "msg": "Note deleted", "id": 12 }

Realtime events

Collaborate without polling.

Connect

Open a WebSocket connection to the same host and pass the JWT in the query string.

wss://wom-2026-rest-api.onrender.com/?token=<your-jwt>

Join a board

Send immediately after connecting. The socket receives events only for an accessible board.

{ "type": "join", "board_id": 2 }

Move a note

Broadcasts position changes to other clients in the board room. Values are rounded numbers.

{ "type": "note_moving", "id": 12, "x": 180, "y": 90 }

Typing preview

Broadcast a temporary note content preview. Content is limited to 5000 characters.

{ "type": "note_typing", "id": 12, "content": "Draft text..." }

Server events

REST changes are broadcast to the board room with a board_id field.

{ "type": "note_created", "board_id": 2, "note": { ... } }

note_updated includes note; note_deleted includes id.

Connections with an invalid or missing token close with code 4001. Closing a socket automatically removes it from its board room.

Errors

Responses use a consistent message field.

StatusWhenExample
400Invalid ID, missing body data, or an out-of-range layout value.{ "msg": "Invalid note id" }
401Missing, expired, or invalid Bearer token.{ "msg": "Authorization required" }
403The authenticated user cannot access the requested board.{ "msg": "No access to board" }
404The note does not exist or is not accessible.{ "msg": "Note not found" }
500Unexpected server or database failure.{ "msg": "Could not fetch notes" }
